How It Works

Flow State is an experimental audio capture tool built entirely on the Fulcra platform.

1.Hands-Free Capture

Musicians shouldn't have to interact with screens while playing. Flow State uses continuous background DSP (Digital Signal Processing) to detect specific audio markers (like a high minor triad). When it hears the marker, it automatically extracts a 30-second window of audio around that timestamp.

2.Semantic Tagging

Instead of just saving a raw audio file, our background worker analyzes the extracted clip using librosa to calculate its exact Key Signature and Tempo (BPM).

3.Backed by Fulcra

Every extracted idea is stored natively in a user's Fulcra account as a custom MusicalIdea data type. We didn't have to spin up a database, manage file buckets, or build complex search APIs. Fulcra automatically structures the raw music data and semantic tags, making it instantly queryable. The app can effortlessly recall all ideas in 'F# minor' or filter by BPM, while the musician maintains absolute ownership of their raw WAV files and metadata in their personal vault.

Technical Details

Flow State uses a Python FastAPI backend to wrap the fulcra-api CLI, acting as a secure bridge between the browser's frontend (MediaRecorder and Wavesurfer.js) and the user's Fulcra vault. The architecture relies on three primary endpoints:

WS /ws?mode={session|marker}

Streams raw audio/webm chunks every 2 seconds from the browser to the FastAPI server to prevent data loss. When the socket closes, FastAPI runs:

fulcra-api file upload temp.webm /agent/flow-state/sessions/raw/session_123.webm

Once the raw session is safely in Fulcra, a background DSP worker using librosa scans the audio, extracts ideas, and pushes MomentAnnotation records back to Fulcra containing the Key and BPM tags.

GET /api/ideas

Instead of scanning a directory of heavy audio files, this endpoint queries Fulcra's metadata layer to hydrate the UI instantly.

fulcra-api get-records MomentAnnotation/c4480... "30 days" fulcra-api tag list

FastAPI joins these responses, resolving the tag UUIDs into semantic strings (key:F#-minor), and returns a clean JSON array. The frontend uses this lightweight payload to group sessions and calculate D3.js timeline highlights.

GET /api/audio?path={fulcra_path}

A proxy route that streams raw audio assets from Fulcra to the browser's wavesurfer.js instances, bypassing WebAudio CORS restrictions.

fulcra-api file download /agent/flow-state/ideas/...wav temp.wav

FastAPI fetches the requested .wav or .webm file directly from the user's private Fulcra vault and returns it as a FileResponse stream.
